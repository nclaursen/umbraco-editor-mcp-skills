# Editable content inventory

Create one entry per relevant existing page. A small reviewed inventory is
more useful than an exhaustive list of guessed topic assignments.

For each entry record URL, source/CMS identity, language, page type, intended
reader, primary question, useful supporting topics, next action and status.
Add important internal links, known overlap and review date with sources.
For maintenance record the known owner, time-bound commitments, expiry dates
and review triggers. Leave unknown ownership or dates explicit.

Keep unpublished drafts identifiable. Two pages mentioning the same topic
are not automatically competing for the same intent. Preserve existing URLs
unless a change and its redirect handling are explicitly in scope.

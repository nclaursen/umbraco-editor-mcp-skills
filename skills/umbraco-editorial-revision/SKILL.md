---
name: umbraco-editorial-revision
description: Revise existing content against an accepted change brief, preserving supported claims and the intended voice. Use when implementing an accepted editorial change brief in local copy or a requested Umbraco draft.
---

When using Umbraco CMS Editor MCP, read
[references/umbraco-editor-mcp.md](references/umbraco-editor-mcp.md) for this
workflow's tool sequence and limits. With supplied files only, use the
editorial workflow below and state which CMS checks are unavailable.

Read the accepted brief, current content and relevant audience, voice and
approved-fact files. Make the changes the brief calls for. Preserve the
argument and useful material outside that scope.

Support new factual claims with supplied or verified sources. If a claim
cannot be supported, omit it or explain the gap outside the article.

Write the proposed revision to the requested output location. Compare it
with the original and report material changes against the brief.

Read the complete revised page for repetition, broken links, unsupported
claims and voice. Do not treat permission to draft as permission to publish.

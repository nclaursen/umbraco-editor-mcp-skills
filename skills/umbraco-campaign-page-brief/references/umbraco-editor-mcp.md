# Campaign planning with Editor MCP

Use `search-content` or `list-children` to find pages that may already serve
the offer; read candidates with `get-page` and `inspect-blocks`. Use
`list-document-types` and `get-document-type` plus inspected reference blocks
to establish page fields and component examples. Use the supplied catalogue
or site configuration for allowed structures and limits that these tools
do not expose. CMS JSON does not establish rendered layout or form behaviour.

Return a brief and verified field/block mapping, with unknowns and required
assets. A campaign brief does not create a page, media, forms, tracking or
publication schedules. If later asked to create the CMS draft, use the
page-drafting skill if available or follow the documented draft tools after
verifying parent, culture and model. This skill's planning work is read-only.
